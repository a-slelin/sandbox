# Правила для Claude в этом репозитории

## Код и команды, которые копирует пользователь

- **Никогда не сокращать** команды и код, предназначенные для копирования. Каждую команду писать **целиком**,
  отдельным блоком, даже если она почти повторяет предыдущую (например, шаги для сервера и для клиента).
- Запрещены формулировки вида «те же команды, но с другим файлом», «аналогично», «и т.д.», `...` вместо кода.
- Если команды для Windows и Linux отличаются — приводить обе полностью.

## Математика и отчёты

- **Не сокращать математические вычисления.** Расписывать каждый промежуточный шаг: подстановку значений,
  преобразования, промежуточные результаты. Не перепрыгивать через несколько шагов сразу.

## Стиль проекта

- Модули — Maven, Java 25; README на русском, оформленные (эмодзи-заголовки, бейджи, таблицы, содержание).
- Комментарии в коде — на русском, понятные.
