# 📬 MailClient

**Настольный почтовый клиент: отправка писем и просмотр входящих**

> Небольшое Swing-приложение, которое умеет отправлять письма через **SMTP** и показывать последние входящие через
> **IMAP** — без браузера и веб-интерфейса почтового сервиса.

## 🎯 О проекте

**MailClient** — модуль песочницы [Sandbox](../README.md): десктопное приложение на **Java Swing**, работающее с
обычным почтовым ящиком (по умолчанию — **Яндекс Почта**) напрямую по стандартным почтовым протоколам.

Окно приложения состоит из двух вкладок:

1. **Отправить** — форма письма: получатель, тема, текст и кнопка «Отправить».
2. **История** — таблица с последними **10** письмами из папки «Входящие»: дата, отправитель, тема и начало текста.

## 💡 Зачем это нужно

Проект учебный — это практика работы с почтой «на низком уровне», без готовых сервисов и SDK:

- как устроены протоколы **SMTP** (отправка) и **IMAP** (чтение) и чем отличаются **STARTTLS** и **SSL**;
- как с ними работает стандартный API **Jakarta Mail** (бывший JavaMail): `Session`, `Transport`, `Store`, `Folder`,
  `Message`;
- как устроено письмо в формате **MIME**: простой текст, `multipart`-письма, вложенные части;
- как в **Swing** выполнять долгие сетевые операции в фоне (`SwingWorker`), чтобы интерфейс не зависал;
- как собрать приложение в один исполняемый **fat-jar**, который запускается двойным кликом или `java -jar`.

## ✨ Возможности

### ✉️ Отправка писем

- Поля «Кому», «Тема» и «Сообщение».
- Проверка перед отправкой: корректный email получателя, непустые тема и текст.
- Тема и текст отправляются в **UTF-8**, поэтому кириллица отображается корректно.
- Отправка выполняется в фоне; статус («Отправка...», «Письмо успешно отправлено», текст ошибки) показывается внизу
  окна.
- После успешной отправки форма очищается.

### 📥 История входящих

- Загрузка последних **10** писем из `INBOX` при открытии и по кнопке «Обновить».
- Новые письма отображаются сверху.
- Для каждого письма показывается дата, отправитель, тема и превью текста (первые **120** символов, пробелы и
  переносы схлопываются).
- Из `multipart`-писем берётся часть `text/plain`, в том числе из вложенных `multipart`.
- Папка открывается **только для чтения** — приложение ничего не меняет в ящике (письма не помечаются прочитанными).

## 🏗️ Архитектура

```text
MailClient/
├── pom.xml
├── config.example.properties          шаблон конфигурации
└── src/main/java/a/slelin/work/mailclient/
    ├── App.java                       точка входа: Look & Feel, загрузка конфига, запуск окна
    ├── ConfigManager.java             чтение config.properties
    ├── MailerGUI.java                 главное окно, вкладка «Отправить»
    ├── HistoryPanel.java              вкладка «История»
    ├── EmailSender.java               отправка писем по SMTP
    └── MailReceiver.java              чтение последних писем по IMAP (+ record MailInfo)
```

Слои разделены: **UI** (`MailerGUI`, `HistoryPanel`) ничего не знает о протоколах и вызывает сервисы
(`EmailSender`, `MailReceiver`), а те берут настройки из `ConfigManager`.

```text
App ──► ConfigManager
 └────► MailerGUI ──► EmailSender  ──► SMTP (smtp.yandex.ru:587, STARTTLS)
           └────────► HistoryPanel ──► MailReceiver ──► IMAP (imap.yandex.ru:993, SSL)
```

## ⚙️ Как это работает

**Отправка** (`EmailSender`):

1. Создаётся `Session` с параметрами `mail.smtp.host/port`, `mail.smtp.auth=true`,
   `mail.smtp.starttls.enable=true` и таймаутами по **10** секунд.
2. Авторизация — через `Authenticator` с логином и паролем из конфига.
3. Собирается `MimeMessage` (от кого, кому, тема и текст в UTF-8) и отправляется через `Transport.send`.

**Получение** (`MailReceiver`):

1. Открывается `Store` по протоколу `imaps` (IMAP поверх SSL) и подключается к серверу.
2. Папка `INBOX` открывается в режиме `READ_ONLY`.
3. Берутся последние `N` писем (`getMessages(total - N + 1, total)`), из каждого извлекаются нужные поля и превью.
4. Список разворачивается (новые сверху), соединение закрывается в `finally`.

**Интерфейс**: сетевые операции выполняются в `SwingWorker.doInBackground()`, а обновление таблицы и статуса — в
`done()`, уже в потоке Swing (EDT).

## 🔐 Конфигурация

Приложение читает файл `config.properties`:

1. сначала — из **текущей рабочей папки** (рядом с `MailClient.jar`);
2. если его там нет — из **classpath** (`src/main/resources/config.properties`, удобно при запуске из IDEA).

Шаблон лежит в [`config.example.properties`](config.example.properties):

```properties
smtp.host=smtp.yandex.ru
smtp.port=587
imap.host=imap.yandex.ru
imap.port=993
email.user=your.name@yandex.ru
email.password=your-app-password
```

| Ключ             | Описание                                    |
|------------------|---------------------------------------------|
| `smtp.host`      | Сервер исходящей почты                      |
| `smtp.port`      | Порт SMTP (587 — STARTTLS)                  |
| `imap.host`      | Сервер входящей почты                       |
| `imap.port`      | Порт IMAP (993 — SSL)                       |
| `email.user`     | Адрес почтового ящика (он же логин)         |
| `email.password` | **Пароль приложения**, а не пароль от ящика |

> ⚠️ Оба файла `config.properties` добавлены в `.gitignore` — пароль **никогда** не должен попадать в репозиторий.

Пароль приложения для Яндекса создаётся в **Яндекс ID → Безопасность → Пароли приложений → Почта**. Также в настройках
почты нужно разрешить доступ по протоколу IMAP: **Все настройки → Почтовые программы**.

Другой почтовый сервис (Gmail, Mail.ru и т.д.) подключается заменой хостов и портов — главное, чтобы SMTP работал через
STARTTLS, а IMAP — через SSL.

## 🚀 Быстрый старт

```shell
# Из корня песочницы собираем модуль (вместе с родителем);
mvn clean package -pl MailClient -am;

# Переходим к собранному jar;
cd MailClient/target;

# Создаём конфигурацию из шаблона и вписываем свои данные;
cp ../config.example.properties config.properties;

# Запускаем;
java -jar MailClient.jar;
```

Из **IDEA** — скопировать шаблон в `src/main/resources/config.properties` и запустить класс
`a.slelin.work.mailclient.App`.

## 🚧 Ограничения

- Только простой текст: без HTML-писем, вложений, копии (CC) и скрытой копии (BCC).
- Один получатель на письмо.
- История — только последние 10 писем из «Входящих», без открытия письма целиком.
- Пароль хранится в открытом виде в локальном файле конфигурации.
- Нет тестов.
